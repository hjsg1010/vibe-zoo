## P-01 — 사내 웹앱으로 업무를 수행하는 사용자

- **목표**: 지금 사용하는 웹앱에서 대화로 업무를 끝내고, 반복할 업무를 직접 가르쳐 다시 사용한다.
- **환경과 특성**: 자신의 브라우저·로그인·업무 권한을 사용한다. 별도 CLI·Agent 앱 실행이나 관리자 사이트 등록 없이 Keeper에서 시작한다. 조직·나이·직급·업무 빈도는 입력에 없으므로 가정하지 않는다.
- **필요**: 사용할 수 있는 기능과 실행 대상을 이해하고, 변경 내용·실제 결과·실패 이유를 확인한다. 개인 Skill과 설정은 Store 게시 없이 저장·재사용한다.
- **제약**: 본인에게 없는 웹앱 권한이나 접근 불가 화면을 자산 설치로 얻지 않는다. 제품의 실행·데이터 경계는 requirements.md의 FR/NFR을 따른다.

| 상황별 역할 | 원하는 결과 | 관련 스토리 |
|---|---|---|
| 업무 실행자 | 도구 준비, 채팅 실행, 개인 설정, 개선 결과 사용, 중단·복구 상태 확인 | US-01, US-02, US-03, US-05, US-08, US-09 |
| 업무 시연자 | Record와 의도로 개인 Skill을 만들어 다른 입력에 재사용 | US-04 |
| 자산 공유자 | 선택한 자산 버전을 동료가 사용할 수 있도록 공유 | US-06 |
| 자산 설치자 | 동료가 공유한 자산을 자신의 환경에서 검증해 사용 | US-07 |

이는 한 페르소나가 수행하는 역할이며 별도 직무·계정 유형을 신설한 것이 아니다. **AC-07 검증에서는 공유자와 설치자를 반드시 서로 다른 사용자·세션으로 구성한다.** 같은 페르소나라는 이유로 계정·대화·브라우저를 공유하지 않는다.

관리자·운영자·Backend Agent는 별도 사용자 페르소나로 추가하지 않는다. 기술 공급자, 미측정 업무 빈도·시간 절감 수치도 페르소나의 사실로 넣지 않는다. 각 역할의 수용조건은 stories.md에서만 정의한다.
