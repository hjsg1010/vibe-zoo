## 1. 전체 스토리 배정

스토리의 전제·역할·FR/NFR·공통 CC·고유 수용조건은 [stories.md](../user-stories/stories.md)를 그대로 참조한다. 아래 AC 열은 그 문서의 연결을 유지하며 조건 전문을 복제하지 않는다. 내부 순서의 정의는 [U-01](unit-of-work.md#3-같은-유닛-안의-구현검증-순서)에 있다.

| 스토리 | 담당 유닛 | 내부 순서 | 기존 AC 연결 |
|---|---|---|---|
| US-01 — 준비된 자산으로 바로 시작 | U-01 | 1 | AC-06 |
| US-02 — 처음 만난 사이트에서 실행할 도구 만들기 | U-01 | 1 | AC-01, AC-02, AC-04, AC-10 |
| US-03 — 요청한 업무를 내 탭에서 끝내기 | U-01 | 1 | AC-03, AC-09 |
| US-04 — 한 번 보여준 업무를 다른 입력으로 재사용 | U-01 | 2 | AC-04, AC-05 |
| US-05 — 내 설정을 저장하고 다음 업무에 적용 | U-01 | 2 | AC-05, AC-06 |

US-01~09를 각각 한 번 U-01에 배정했다. 빠진 스토리·추가 유닛은 없으며 AC-01~10 전체가 연결된다. 같은 AC가 여러 스토리에 연결되더라도 한 경로의 성공으로 다른 경로의 검증을 대체하지 않는다.

## 2. 연결 검토와 공통 조건

- **AC-04**: US-02의 생성 도구와 US-04의 개인 Skill에서 각각 다른 입력을 검증한다.
- **AC-05·06**: US-01의 생성 기본 Skill 설정 노출, US-04의 개인 Skill 생성, US-05의 편집·기본값 변경·저장·재접속·후속 채팅 재사용을 해당 원문 조건대로 연결한다.
- **AC-07·08**: 공유 설치와 개선 모두 U-01 완료 범위다. 서로 다른 설치자의 자체 검증과 실패/관련 성공 사례·버전 보존 조건을 유지한다. 개선의 수정·추가 시연은 공통 계약의 선택적 보조 근거다.
- **US-09 / AC-09**: 첫 실행부터 생성·학습·설치·개선의 해당 경로에서 계속 적용한다. 공통 CC-01~08은 stories.md의 단일 정의를 참조하고, 조회·설정처럼 브라우저 실행이 필요 없는 작업에 실행 탭을 추가로 요구하지 않는다.

모든 스토리의 공통 완료 조건인 NFR-05·07·08 및 [requirements.md 6절](../requirements/requirements.md#6-수용조건과-완료-증거)의 실제 재현·제출 증거도 포함한다. 나머지 NFR은 각 스토리의 기존 연결을 따른다. 각 조건이 구체적인 코드와 검증 결과에 연결되는 기록은 이후 기존 유닛/Construction 문서를 갱신해 남기고 별도 중복 추적 문서를 만들지 않는다.
