# Vibe Zoo — Unit Dependencies

**상태**: 승인된 [분해 계획](../plans/unit-of-work-plan.md)에 따라 생성·검토하고 2026-09-08T10:50:12Z 사용자 승인을 확인했다. 유닛 정의와 구현 순서는 [unit-of-work.md](unit-of-work.md)를 참조한다.

## 1. 유닛간 의존성 행렬

행은 의존하는 유닛, 열은 선행 유닛이다.

| 유닛 | U-01 / vibe-zoo-mvp |
|---|---|
| U-01 / vibe-zoo-mvp | — 자기 자신을 별도 선행 유닛으로 두지 않음 |

다른 개발 유닛이 없으므로 유닛간 선행 관계도 없다. **내부 컴포넌트와 외부 실행 환경의 의존성은 존재한다.** 단일 유닛 매트릭스에 서버·worker·브라우저를 추가 유닛으로 넣지 않는다.

## 2. 내부 의존성과 통합

[component-dependency.md](component-dependency.md)의 행렬·통신 경계·흐름도가 컴포넌트 관계의 원본이다. C-03의 조정, C-04의 후보 출력, C-05/C-02의 실제 실행·검증, C-06의 버전·설정 반영 계약을 재사용한다.

U-01의 첫 실행 경로는 Extension과 Backend의 필요한 모듈을 함께 연결한다. 생성된 자산을 개인 학습이 재사용하고, 검증된 자산·사용자별 연결을 공유 설치와 개선이 재사용한다. 이 순서는 유닛 내부의 구현·검증 순서이며 후속 기능을 위한 별도 가상 유닛이나 물리 배포 선행 관계가 아니다.

대화·작업·브라우저 연결과 개인/공유 자산의 소유 경계는 유닛 정의와 기존 공통 계약을 따른다. 공유 Store의 게시·가입은 개인 생성·학습·실행의 선행 조건이 아니다. 브라우저가 필요 없는 설정·목록 조회에 실행 탭을 필수 입력으로 추가하지 않는다.

## 3. 외부 실행 전제와 확인 위치

| 전제 | 이 유닛이 의존하는 내용 | 확인할 위치 |
|---|---|---|
| 사용자 Chrome과 현재 웹앱 | 요청 사용자의 연결·탭·문서·출처·로그인/권한, 관찰 가능한 화면 | Functional/NFR Design에서 경계 정의; Code Generation에서 실제 대상 확인·잘못된 대상 거절·사후 상태 검증 |
| 모델 및 Agent 실행 수단 | 생성·학습·다단계 요청 처리에 사용할 수 있는 모델/엔진과 필요한 접근 설정 | NFR Requirements에서 후보·접근성·제약 정리; 승인된 Code Generation에서 실제 확인 |
| MCP와 Browser Bridge | 실제 도구 검색/호출을 정확한 사용자 브라우저 실행에 연결하는 계약과 통신 | NFR/Infrastructure Design에서 선택 근거 정리; Code Generation에서 MCP→Bridge→업무 결과와 단절·취소 검증 |
| 어댑터와 MV3·배포 경계 | 생성한 실행 표현을 목표 Extension 환경에서 전달·수행할 수 있는 방식 | NFR/Infrastructure Design에서 후보·제약 검토; Code Generation에서 다른 입력과 실제 실행 적합성 확인 |
| 자산·설정·작업의 보존 | 버전·개인/공유·재접속·취소 일관성을 유지할 저장 및 동시 처리 수단 | Functional/NFR Design과 Infrastructure Design에서 방식 구체화; Code Generation에서 재사용·늦은 결과·버전 경합 확인 |
| 공유·개선 검증 자료 | 서로 다른 사용자/세션의 설치, 재현 실패와 관련 성공 사례 | 개인 사용 경로 완성 후 해당 Code Generation 순서에서 확인; 전체 Build and Test에서 통합 재현 |

제품 모델 공급자·엔진·MCP transport·Bridge·저장·worker·배포는 현재 미정이다. 표의 항목은 특정 공급자·서비스·독립 배포 구조를 선택한 결과가 아니다. 사용자 웹앱의 사전 코드 수정·공개 API·Native WebMCP·관리자 URL 등록이나 별도 CLI/Agent 앱 실행을 의존성으로 추가하지 않는다.

첫 실제 전체 흐름은 MinIO Console이며 다른 미등록 사이트도 같은 추출 요청 경로로 들어간다. 사이트 전체·모든 프레임 지원이나 MV3/공개 배포 적합성은 아직 입증되지 않았다. 필요한 실제 주소·계정·키·런타임 값은 저장소 밖에서 주입하고 공개 예시는 합성 자료를 사용한다.
